Super basic plotter for partial(projected) densities of states (PDOS) generated by SIESTA.
It plots the DOS projected atom-wise, for a single atom (+-shifted around Fermi level).

I made it for users that are unfamiliar with editing code, so it is slightly interactive 
and doesn't require an installation, it can be run in a google colab notebook if you load the 
PDOS file, such as:

https://colab.research.google.com/drive/1_KECo0xihMZV4STIhfXnsimo7EwjG5Ub?usp=sharing
(file -> upload file or drag& drop PDOS file -> use its name minus the .PDOS extension to plot the orbitals)

Note: This plotter only works for DZ-outputs (column format).

If ran locally, the needed packages are:

numpy,
matplotlib,
os
